# Getting Started with Vite + React

This project uses [Vite](https://vite.dev/) as the build tool for React.

## Available Scripts

In the project directory, you can run:

### `npm run dev` or `npm start`

Runs the app in development mode.\
Open the local URL shown in terminal (usually [http://localhost:5173](http://localhost:5173)).

The page will reload when you make changes.\
You may also see any lint errors in the console.

### `npm test`

Launches the test runner in the interactive watch mode.\
The project keeps Jest-based test config from the original setup.

### `npm run build`

Builds the app for production to the `dist` folder.

### `npm run preview`

Previews the production build locally.
